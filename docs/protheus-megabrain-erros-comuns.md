# Erros comuns — Protheus Mega Brain

O menu Erros comuns no cabeçalho do gerador abre o catálogo em `public/solucoes/protheus-mega-brain/erros-comuns.html`. A página possui link para retornar ao Gerador SX3.

O primeiro artigo registra a mensagem de índice sem Mostrar Pesq., com a captura fornecida pelo usuário em `assets/images/erro-indice-mostrar-pesq.png`. A resolução informada pelo usuário é abrir Dicionário de dados, selecionar a tabela citada, abrir Índices, selecionar o índice da filial, marcar Mostrar Pesq., salvar e atualizar o banco de dados. ZA4 é apenas a tabela do exemplo.

Novos erros podem ser adicionados como artigos na mesma página, com mensagem, captura e passos de resolução.
