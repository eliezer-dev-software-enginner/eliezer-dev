# Utilitário de legendas

Em Protheus Mega Brain, a seção Utilitário: legendas do browse permite configurar alias, campo de status, nome da função, códigos, descrições e cores. Adicione ou remova linhas e copie separadamente os três trechos.

- AddLegend: inserir antes de oBrowse:Activate().
- MenuDef: adicionar a opção Legenda ao array aRotina.
- BrwLegenda: inserir a função no fonte; seu nome deve corresponder à ação do menu.

Os códigos iniciais 1=Disponível, 2=Em uso, 3=Baixado são exemplos. Confirme o domínio no SX3. Salve o PRW em Windows-1252. A ferramenta não altera o projeto nem o ambiente Protheus. Os botões usam o mecanismo de cópia existente do site. Não há persistência das edições deste utilitário.

Ao adicionar uma legenda, o código sugerido é o maior código numérico atual mais um. Códigos vazios ou não numéricos são ignorados; sem códigos numéricos, começa em 1. O código continua editável.
